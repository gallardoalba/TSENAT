# Access analysis results via recommended accessor methods

Access analysis results via recommended accessor methods

## Usage

``` r
getMeta(object, ...)
```

## Arguments

- object:

  TSENATAnalysis object

- ...:

  Additional arguments (method-specific)

## Value

data.frame or list depending on accessor method. See Details for
specific return types.

## Details

Use these accessor methods instead of direct slot access with '@'
