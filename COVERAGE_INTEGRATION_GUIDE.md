# Code Coverage Integration Guide

## Overview

This guide explains how code coverage data from `cobertura.xml` has been
integrated into the TSENAT interactive dependency visualization. Three
versions of the visualization are now available with increasing levels
of detail.

## Data Integration Architecture

### Coverage Data Source

- **File**: `coverage/cobertura.xml`
- **Generated by**: R `covr` package
- **Format**: Cobertura XML (line-level coverage metrics)
- **Last updated**: April 18, 2024

### Integration Process

    cobertura.xml
        ↓
    integrate_coverage.py (parses XML, extracts metrics)
        ↓
    Coverage JSON (embedded in HTML)
        ↓
    JavaScript visualization layer
        ↓
    Interactive HTML + Analytics Dashboard

### Data Available in HTML

Each visualization file includes:

``` javascript
window.coverageData = {
    overall: {
        line_rate: 0.832,
        lines_covered: 13640,
        lines_valid: 16385,
        coverage_pct: 83.2
    },
    r_files: {
        'R/analysis.R': {
            name: 'analysis.R',
            coverage_pct: 85.1,
            line_rate: 0.851,
            methods: {...}
        },
        ...
    }
}
```

### Advanced Analytics Data

The advanced version includes:

``` javascript
window.coverageAnalytics = {
    overall: { ... },
    files: {
        'R/file.R': {
            coverage_pct: 85.1,

            lines_valid: 194,

        },
        ...
    },
    by_level: {
        high: [/* 40 files */],

    }
}
```

## Updating Coverage Data

To regenerate coverage and update visualizations:

### Step 1: Run coverage analysis

``` bash
cd /home/nouser/galaxy/tools_source/TSENAT
Rscript -e 'covr::codecov()' # or appropriate covr command
```

### Step 2: Regenerate integrations

``` bash
python3 integrate_coverage.py
python3 enhance_coverage_analysis.py
```

### Step 3: Open updated HTML files

The new coverage metrics will be embedded automatically.

## Integration Scripts

Two Python scripts handle the integration:

### 1. `integrate_coverage.py`

- Parses `cobertura.xml`
- Extracts per-file and per-method coverage
- Creates basic coverage panel
- Embeds coverage JSON in HTML

### 2. `enhance_coverage_analysis.py`

- Performs detailed coverage analysis
- Creates advanced analytics dashboard
- Generates `COVERAGE_REPORT.md`
- Adds interactive filtering capabilities

**Run either script anytime to regenerate:**

``` bash
python3 integrate_coverage.py          # Basic version
python3 enhance_coverage_analysis.py   # Advanced version
```

## Troubleshooting

### Coverage data not showing?

- Check browser console for errors (F12)
- Verify `cobertura.xml` exists and is readable
- Clear browser cache and reload
- Try different browser

### HTML file too large?

- Files are ~8.4 MB (compressed HTML + embedded data)
- First load may take 2-3 seconds
- Subsequent navigation is fast (cached)

### Wrong coverage percentages?

- Verify `cobertura.xml` is current
- Regenerate with `covr` package
- Re-run integration scripts

### Can’t toggle coverage panel?

- **Alt+C** keyboard shortcut (advanced version only)
- Works in advanced_coverage version only
- Click on panel to interact with it

## Advanced Usage

### Programmatic Access

Access coverage metrics from any webpage using same browser:

``` javascript
// In browser console
fetch('r_dependencies_s4_interactive_advanced_coverage.html')
    .then(r => r.text())
    .then(html => {
        const match = html.match(/window\.coverageAnalytics = ({.*?});/)
        const data = JSON.parse(match[1])
        console.table(data.by_level)
    })
```

### Export Coverage Report

Generate markdown report:

``` bash
cat COVERAGE_REPORT.md
# Use for test planning and documentation
```

### Customize Coverage Thresholds

Edit scripts to change color thresholds:

In `enhance_coverage_analysis.py`:

``` python
if coverage_pct >= 80:  # Change threshold here
    coverage_by_level['high'].append(...)
```

## FAQ

**Q: Why are some files showing 0/0 lines?** A: These are likely
configuration or stub files. The coverage dashboard shows actual
percentages despite zero line counts.

**Q: How often should I update coverage?** A: After adding significant
new tests (~10+ tests) or major code changes.

**Q: Can I share the HTML files?** A: Yes! Files are self-contained (~8
MB) and work offline. Coverage data is embedded.

**Q: How do I integrate with CI/CD?** A: Add integration scripts to your
build pipeline after `covr` generates cobertura.xml.
